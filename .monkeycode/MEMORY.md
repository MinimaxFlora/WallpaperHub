- Context: Discovered by Agent while implementing the Go wallpaper service
- Category: Build Methods
- Instructions:
  - Regenerate the image manifest with `go run ./cmd/manifest -root . -out manifest.json`. It is idempotent: when image metadata and bytes are unchanged it leaves `manifest.json` untouched, so re-running it cannot create empty commits.
  - Compilation, `go test` and `go vet` must run through managed background terminals per the repository resource-limit rule.
  - The Docker image pins `golang:1.27.1-alpine`, so the toolchain is not downloaded during container builds.
  - TLS is not handled by the Go service. The Compose stack publishes the API on `127.0.0.1:8080` only; the host's Caddy owns 80/443, obtains certificates for every site and reverse-proxies the wallpaper domain to the container. Validate Caddyfile changes with `caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile`.

  - The VPS sshd closes rapid successive connections with `kex_exchange_identification: Connection closed by remote host`; retry after a pause and reuse one connection via `ssh -o ControlMaster=auto -o ControlPath=<sock> -o ControlPersist=600` for the rest of the session.
